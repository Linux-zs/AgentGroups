# 在另一台 Windows 电脑独立使用

1. 将 `agentgroups-windows.zip` 复制到新电脑，右键「全部解压」，放在打算长期保留的目录。
2. 双击 `启动群聊.cmd`。首次需要联网，会下载官方 Node.js 24.17.0 并核对 SHA256，然后安装固定依赖、构建、生成本机凭据和合并客户端配置。
3. 安装并登录 Qoder、WorkBuddy、OpenCode（本包不安装这三个软件）。已打开的客户端需要重新启动。
4. 在 WorkBuddy 的 MCP/连接器设置中找到 `agentgroups`，批准/信任并启用。脚本不会修改客户端信任记录。
5. 网页选择参与成员并创建话题，在选定客户端发送 `docs/prompts` 中对应提示。成员确认就绪后点击开始；每轮等齐后才推进。

以后仍双击同一个入口启动。关掉启动窗口不会停止后台；电脑重启后需要重新双击。第一版没有开机自启或自动唤醒。

## 配置与恢复

- Node.js 放在项目 `.runtime`，不要求管理员权限，不修改系统 PATH。
- 配置写入当前用户 `.qoder/settings.json`、`.workbuddy/mcp.json`、`.config/opencode/opencode.json`（已有 JSONC 时使用 JSONC）。保留其他服务和注释，只更新 `agentgroups`。
- 已有文件在修改前备份到 `.local/config-backups/<时间>/`。恢复时先退出对应客户端，再将备份复制回原路径。
- 配置格式损坏或 OpenCode 同时存在 JSON/JSONC 时停止配置，不覆盖原文件。端口 4318 被其他服务占用时停止，不终止其他进程。
- 不要搬动已配置目录；如果搬动，重新运行入口并重启客户端，以更新绝对路径。
- 打包只包含源码和说明，不包含 `.local`、`.runtime`、`node_modules`，因此不会迁移旧电脑的凭据、历史或信任记录。
- 独立电脑应使用全新解压目录。不要复制旧电脑的 `.local`。

## 验证范围

脚本配置与服务运行不代表桌面会话接通。需要分别确认真实客户端调用 `room_info` 的身份，以及真实发言出现在网页上。项目不模拟其他客户端消息。

本机测试覆盖配置合并、JSONC 注释保留、重复执行及损坏文件拒绝；另一台干净 Windows 电脑的下载、首次运行和桌面批准流程仍待实测。
